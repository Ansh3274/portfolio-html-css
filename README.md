# Ansh Kumar — Personal Portfolio

A simple, responsive personal portfolio website built from scratch using HTML5 and CSS3.

The website showcases my skills, projects, education, technical interests, and ways to connect with me.

## 📌 About the Project

This portfolio was created to present my work and development journey in a clean and modern way.

The design is inspired by modern creative portfolio layouts, with a dark background, orange accents, rounded sections, large typography, and responsive project cards.

The website is intentionally built without any frameworks to demonstrate a strong understanding of HTML and CSS fundamentals.
